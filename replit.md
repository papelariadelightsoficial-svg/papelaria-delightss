# Papelaria Delights

## Run on Replit

The project is a React/Vite storefront. The configured `Start application` workflow runs:

```bash
npm run dev -- --host 0.0.0.0 --port 5000
```

For a production bundle, run:

```bash
npm run build
```

The storefront remains compatible with the existing GitHub Pages setup and uses assets from `public/`.
